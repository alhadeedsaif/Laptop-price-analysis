# 💻 Laptop Price Analysis & Exploratory Data Analysis (EDA)

A comprehensive end-to-end data analysis project exploring laptop market specifications, pricing trends, and key performance factors using Python.

---

## 🚀 Project Overview
This project focuses on cleaning, standardizing, and analyzing a laptop dataset (1,303 rows) to uncover the hidden relationships between laptop pricing and hardware specifications such as brands, processors, and RAM sizes.

---

## 🛠️ Tech Stack & Libraries
* **Python**
* **Pandas & NumPy** (Data cleaning, manipulation, and feature engineering)
* **Matplotlib** (Data visualization and plotting)
* **Jupyter Notebook** (Development environment)

---

## 📊 Key Workflow & Analysis Steps
1. **Data Cleaning & Preprocessing:** Stripping unit strings from numeric columns (`Ram`, `Weight`) and converting data types.
2. **Feature Engineering:** Extracting and standardizing core CPU brands and unifying operating system categories (`OpSys`).
3. **Exploratory Data Analysis (EDA):** Utilizing statistical aggregation (`groupby` and `pivot_table`) to analyze average prices across manufacturers, processors, and memory sizes.
4. **Data Visualization:** Generating professional bar charts and horizontal layouts to clearly represent price distributions.

---

## 💡 Key Insights & Findings
* **Manufacturer Positioning:** Premium brands and workstation-focused manufacturers command significantly higher average price points.
* **Processor Impact:** High-end CPU series (like Intel Core i7) heavily drive up overall laptop prices.
* **Memory Scaling:** A clear, consistent positive correlation exists between RAM capacity (e.g., 4GB, 8GB, 16GB+) and the final price tag.
